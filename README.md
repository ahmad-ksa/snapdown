# SnapDown

تطبيق Android لتحميل الفيديو والصوت من مواقع التواصل (يوتيوب، تيك توك، إنستقرام، فيسبوك، X، سناب شات، وأكثر من 1000 موقع) — بدون إعلانات ولا تتبّع.

- الصق الرابط أو شارك المنشور إلى التطبيق مباشرة.
- اختر الجودة (حتى 4K) أو صوت MP3.
- تحميل في الخلفية مع إشعار تقدم، وأكثر من تحميل في نفس الوقت.
- الملفات تُحفظ في `Movies/SnapDown` و `Music/SnapDown` وتظهر في المعرض.
- محرك التحميل (yt-dlp) يتحدث تلقائيًا كل يوم.

ملف APK الجاهز في صفحة **Releases**. اختر `SnapDown-arm64.apk` لأغلب الجوالات الحديثة.
